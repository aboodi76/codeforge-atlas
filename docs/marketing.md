# CodeForge Atlas — Marketing Assets

This document consolidates the public-facing marketing materials for CodeForge Atlas so that anyone promoting the project uses consistent positioning, taglines, and links.

## Positioning

CodeForge Atlas is an evidence-first AI workspace for developers. It maps codebases, predicts change impact, and generates documentation, tests, and verification plans — with evidence before assumptions. The core value proposition in one sentence:

> Know the blast radius before you change code.

## Key facts for submissions

- Open source (MIT), built with React 19, Tailwind 4, Express, tRPC, Drizzle + MySQL.
- Four pillars: change preflight (evidence vs. assumptions), system mapping, auto docs & tests, engineering memory (searchable session history).
- Private by default — sessions are never shared or indexed.
- Owner and maintainer: aboodi12.
