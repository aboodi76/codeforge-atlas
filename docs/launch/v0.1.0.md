# CodeForge Atlas v0.1.0 — Public Beta

CodeForge Atlas begins as an evidence-aware change-intelligence workspace for developers working in unfamiliar or sensitive code paths.

## Included in this release

| Area | Delivered capability |
|---|---|
| Change preflight | Analysis based on submitted source and the developer's stated intent. |
| Trust model | Explicit evidence, assumptions, confidence, and verification guidance. |
| System understanding | A lightweight map of nodes and links supported by the supplied artifact. |
| Engineering assistance | Review insights, documentation drafts, test guidance, and contextual chat. |
| Workflow continuity | Authenticated sessions with searchable history and stored reports. |
| Contributor readiness | CI, test coverage, contribution standards, security reporting, and issue templates. |

## Important limits

Atlas does not execute code, access unseen repository material, or replace human code review. Users must not submit secrets, credentials, private source code without authorization, or regulated data. This is a public beta; feedback and contributions are welcome through GitHub Issues.
